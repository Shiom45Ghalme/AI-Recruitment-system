How to set up Google Calendar OAuth 2.0 (One-time)
  1. Go to the Google Cloud Console and create a project (e.g. AI Recruitment).
  2. Go to APIs & Services > Library, search for Google Calendar API, and click Enable.
  3. Go to OAuth consent screen:
    • User type: External
    • App name: AI Recruitment System
    • Add your email under Test users (since the app is in testing mode).
  4. Go to Credentials > Create Credentials > OAuth Client ID:
    • Application type: Desktop app (or Web Application).
    • Name: Recruiter Calendar Client.
  5. Click Download JSON, rename the downloaded file to credentials.json, and place it inside the Automate_recruitment folder.
  6. Return to this page and click Authorize Google Calendar Now. A browser popup will open allowing you to sign in and grant calendar access. The system handles all token management and automatic background refreshes from then on!
